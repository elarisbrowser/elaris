# Elaris 0.1.0-alpha.1

The first experimental alpha. Elaris is a browser written in Rust that uses Ladybird's engine. This release is for
testing, not daily use.

## What works

- Browsing with tabs and windows, with session restore after the browser is closed or killed.
- Downloads with progress, pause, resume and retry, which survive restarts.
- History, with search, and removing one address or everything.
- Settings for appearance, the sidebar and browsing.
- Private windows, which keep their data in memory.

## Platforms

- macOS 14.4 or newer on Apple Silicon.
- Linux on x86_64, with glibc 2.43 or newer and a Vulkan driver. Ubuntu 24.04 does not meet the glibc requirement.

Intel Macs and Linux on ARM64 are not built.

## Known limitations

- The macOS app is not notarized, so the first launch needs approval in System Settings.
- The Linux build has been tested in a container, not on a real desktop. Wayland, X11, GPU, clipboard and DPI behaviour
  is unverified.
- The sandbox has not yet been checked on a native x86_64 machine.
- Crash reports are not sent anywhere.
- Expect rough edges and breaking changes between alpha builds.

## Reporting problems

Open an issue at https://github.com/elarisbrowser/elaris/issues with your platform, the version from the release page,
and the steps to reproduce the problem. Please do not attach browsing history or session files.
