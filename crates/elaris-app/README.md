# `elaris-app`

The executable entry point for the Photon browser. It starts the `elaris-shell` application and is built by the repository's `elaris` command.

## Run

From the repository root:

```sh
elaris setup
elaris run
```

Use [`elaris-cli`](../elaris-cli/README.md) for the development commands and [`elaris-shell`](../elaris-shell/README.md) for the native browser window implementation.
