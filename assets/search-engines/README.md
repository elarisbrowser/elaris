# Search engine icons

These are bundled provider assets used in the search engine picker.

- `google.svg`: Google G product icon from `https://fonts.gstatic.com/s/i/productlogos/googleg/v6/24px.svg`.
- `duckduckgo.svg`: Dax Solo SVG from DuckDuckGo's official press pack at `https://staticcdn.duckduckgo.com/press/DuckDuckGo-Brand-Logo.zip`.
- `bing.svg`: Bing's full-colour ribbon mark from `https://svgcode.com/icons/brand-logos/bing`, centered in a square viewBox to preserve its shape at small icon sizes. Its appearance matches Microsoft's current [Bing trademark guidelines](https://cdn-dynmedia-1.microsoft.com/is/content/microsoftcorp/microsoft/mscle/documents/presentations/Bing_Trademark_Guidelines_2026.pdf).
- `brave.png`: Brave's favicon from `https://brave.com/favicon.ico`, converted to PNG for the bundled image.
